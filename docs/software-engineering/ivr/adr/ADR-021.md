# ADR 021: Whole-word keyword intents

## Context
The live turn engine maps a few English and French words onto canned phrase ids, including goodbye. This feature needs five card actions in English, French, Hebrew, Arabic, and Swahili, matched from short sentences, without an intent model. The turn engine uses this router after language selection.

## Decision
- Add `route_intent` in `services/ivr/intent_router.py`. It returns one of `get_balance`, `get_pin`, `get_card_statement`, `block_card`, `unblock_card`, or nothing.
- Only the selected language's keywords are used. The words are: English balance, pin, statement, block, unblock; French solde, pin, relevé, bloquer, débloquer; Hebrew יתרה, פין, דוח, חסום, שחרור; Arabic رصيد, pin, كشف, حظر, تنشيط; Swahili salio, pin, taarifa, zuia, fungua.
- Normalize by casefold, stripping punctuation, and stripping combining marks (French accents, Hebrew niqqud, Arabic tashkeel), then split on spaces. A keyword matches only as a whole token, or as a run of whole tokens. "Unblock" is not "block".
- If the utterance matches two different actions, or none, the result is no match. Goodbye is not an action.
- `map_placeholder_intent` runs only when no action keyword matched, so goodbye still ends the call. A sentence with two actions is not passed to that older map, which would play the first keyword it sees.

## Trade-off Analysis
- **Benefit:** The five languages can be tested from transcripts, with the same rule for each, and the current call flow keeps working.
- **Drawback:** A sentence that avoids the keyword does not match. An Arabic or Hebrew prefix stuck to the keyword, such as the definite article, does not match either, because the match is whole tokens.
