# ADR 004: Detect the email language, echo the same text

## Context
An SMS detects the language of its one body with `py3langid` before the reply is chosen. An email has the same need, and it does not have the SMS time limit. The echo reply stays the inbound plain text. Detection must not choose that text.

## Decision
- Use the same `detect_language` function as SMS. It lives in `services/language.py`. SMS imports it from there.
- Run it on every non-empty plain-text body after the password check and before the Mail Send call.
- A blank body or a detector failure is `en` with score `0.0`. A blank body still sends nothing.
- The reply body stays the inbound plain text.
- The reply log is one JSON line with the language code and the score. The body and the subject are not in that line.

## Trade-off Analysis
- **Benefit:** Email and SMS share one offline detector, and a later reply language can use the code without changing this echo.
- **Drawback:** A short body is a weak sample. The code is recorded and then ignored by the echo.
