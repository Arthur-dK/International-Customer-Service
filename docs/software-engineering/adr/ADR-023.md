# ADR 023: One canned line per action, and the PIN is not spoken

## Context
A routed action still played the old English and French placeholders. The PIN line said "one two three four" / "un deux trois quatre". Hebrew, Arabic, and Swahili had no reply text. Every allowlisted number was already meant to hear the same line.

## Decision
- Each of the five actions has one catalog line. Every allowlisted number hears that same line. The line is not looked up from an account.
- The PIN line does not contain digits or a run of spelled-out numbers. It says the PIN will not be spoken, and that the line is a placeholder.
- Those lines, the task menu, and "I did not catch that" exist in English, French, Hebrew, Arabic, and Swahili.
- Block and unblock still play their result line as soon as the action matches. Asking yes or no before that line is a later phase.

## Trade-off Analysis
- **Benefit:** A caller can hear a finished placeholder for every action, in the language they selected, without a PIN being read out.
- **Drawback:** On this PC only English has a voice, so Hebrew, Arabic, and Swahili text is spoken as the English line until a matching voice exists. The balance line still says a placeholder amount.
