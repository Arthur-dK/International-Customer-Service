# ADR 028: Same allowlist, translated rejection, empty body stays silent

## Context
Voice already rejects numbers that are not in `core/telephony/allowed_callers.json`. SMS uses the same Twilio number. The echo must not answer every sender, and a text with no characters is not a message to copy.

## Decision
- SMS reads the same allowlist file as voice. There is no second list and no environment override.
- A non-empty `Body` from any other number gets one SMS. The text is the existing line from `not_recognised_say`: English, French, Hebrew, or Arabic for that country’s prompt language, and English otherwise.
- A missing `Body` or a body of `""` sends nothing, including no rejection. Whitespace is not empty.
- Pictures are ignored. A caption is still `Body`.
- Logs may include `From`, `To`, and `MessageSid`. They must not include the message body.
- Phase 3 sends that rejection. A picture with no caption sends nothing. A caption is still `Body`.

## Trade-off Analysis
- **Benefit:** One list gates calls and texts. The rejection words already exist for voice.
- **Drawback:** A number on the voice list can also receive the SMS echo. An empty text is dropped with no notice to the sender.
